## What's new

- **Presets.** Slowness triage (Invoke-NetTriage), Tune-up (Invoke-EndpointTuneUp) and Drivers & firmware (Invoke-UpdateSystem) pick the matching modules in one click, or with `--preset` on the command line.
- **Network triage.** Latency and packet loss to the gateway and DNS server, proxy settings (WinHTTP and the signed-in user's), the route in use with its gateway and DNS servers, each DNS server asked directly, the public IP, and a destination test: type a host and ports for DNS, a TCP connect per port, the route the PC picks, and ping.
- **Richer baseline.** Make, model, serial (can be redacted), BIOS, motherboard, signed-in user, uptime and pending restart; overall CPU load; disk latency; VPN evidence that tells a running Cisco Secure Client or Zscaler from an active tunnel.
- **Before and after.** Each run is compared with the most comparable earlier run: problems resolved, new, still failing or changed, and every measurement (round trips, loss, DNS and connect times, disk latency, CPU, memory, free space, signal) as better or worse, with gaps called out. Compare any two saved runs from History, or with `--compare`.
- **Tune-up modules.** DNS flush and re-registration, ARP and NetBIOS purge, TCP autotuning and adapter power, network stack reset (refused on static addresses), adapter restart with DHCP renew, temp cleanup across all profiles, Recycle Bin, DISM and SFC, drive optimisation, Group Policy refresh, Configuration Manager actions, and a restart with a 60-second warning.
- **Preview.** Turn on PREVIEW (or `--what-if`) and every change says exactly what it would do, including the files it would delete and the updates it would install, without changing anything.
- **Remote-safe.** One switch (or `--remote-safe`, or the site profile) locks everything that could drop a remote session or restart the PC.
- **Restart handling.** When a change needs a restart, a banner names it and offers Restart in 60 s and Cancel restart.
- **Updates.** An install button on each pending Windows update, the current BIOS, all ten of Invoke-UpdateSystem's manufacturers routed to their tool, a one-click install of a missing Dell, HP or Lenovo tool, and no firmware installs on battery.
- **Command line.** Give the app arguments and it runs without a window: presets, a destination, preview, remote-safe, JSON or text output, `--out`, one-click fixes and compare. Exit codes match the toolkit: 0, 1, 2, and 3010 when a restart is needed.
- **Site profile settings.** The network probes, Invoke-NetTriage's alert thresholds, serial redaction, Windows Update drivers, temp file age, history size and remote-safe can all be set per site.
- **Exports.** A full transcript with every module's log, and a plain-text transcript saved beside each run in the history folder. Reports now record the itriage version and the exit code.
- **Fixed.** The README named the PowerShell scripts wrongly; it now maps each script and switch to what replaces it, and lists what isn't carried over.
