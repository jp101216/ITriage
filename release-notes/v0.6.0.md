The themes release: the technician console now comes in nine looks, from the red HUD to a flat, quiet one, and you can try each one on before you keep it.

Every file now has a SHA-256 in `SHA256SUMS.txt` and a build-provenance attestation: `gh attestation verify <file> -R jp101216/ITriage` proves it was built by this repository's Release workflow (see "Checking a download" in the README).

## What's new

- **Nine themes.** Critical Red Alert (the default), Wasteland Amber, Atomic Phosphor, Sub Radar, Cyber-Tactical, Holographic HUD, Tactical, Sleek Minimalist and Enterprise Glass. Each is more than a colour swap: the terminal themes run monospace with scanlines and `[ ]` / `[X]` checkboxes, Tactical cuts its corners, Sleek Minimalist drops the glow for flat pill buttons, and Enterprise Glass frosts its panels over a soft gradient.
- **Try before you keep.** **Theme** in the header opens the picker. **Equip** switches the whole console at once, live scopes included; **Apply changes** keeps it, and **Cancel / Close** or Esc puts the old one back. Your pick is remembered on that computer.
- **A site default.** `[ui] theme = "minimal"` in a site profile sets the console's default look. A technician's own pick still wins on their computer, and a name this version doesn't know falls back to red rather than breaking the profile.
- **Meaning stays put.** Warnings stay amber and critical findings stay red in every theme, even on the green phosphor screen, and the disk gauge turns critical-red near full.
- **Unchanged:** the self-service view keeps its calm teal look whatever the console's theme.
- **Fixed:** in the self-service view, hovering **Go ahead** on a fix no longer turns it the console's red.

## Testing status

- 130 automated tests on Linux; clippy clean on Linux and for the Windows target.
- Every theme was screenshotted in Chromium (the engine behind WebView2 on Windows) at desktop size and at 400 px wide (no sideways scrolling), idle, mid-run and after a triage run, and rendered in WebKitGTK 2.52 (the Linux app's engine). The default theme was compared pixel by pixel with 0.5.0 and only glow halos differ, by at most 11 of 255 levels.
- The picker was driven end to end in the browser preview: equip, cancel, Esc, keyboard, apply, reload, the profile default, and a saved pick beating it. The 0.5.0 interface checks all still pass.
- Themes only change how itriage looks: nothing about what it checks, fixes or installs.
