# ITriage 0.8.0 — Advanced troubleshooting cases

Eight investigation capabilities connect the diagnostic checks to a reviewable
case for escalation:

- Application connection checks: profile-defined HTTP/HTTPS endpoints with DNS,
  direct routing/TCP, proxy context, normal TLS validation and expected statuses.
- Bounded intermittent recordings: CPU/RAM, disk/network rates, connection
  probes and Wi-Fi state, with problem markers, safe stop and replay.
- Windows Entra/Microsoft 365 diagnostics: device join/authentication and
  context-aware PRT/WAM/Hello status without reading tokens.
- Existing Wi-Fi, wired 802.1X and certificate-related authentication history,
  retaining timestamps/reason fields and explicit log-availability gaps.
- Recent changes timeline, including update, installer, driver, policy,
  service and restart evidence, with onset-window filtering.
- Cross-host working-PC configuration baselines, with role/platform checks
  and unique identifiers/live metrics excluded from drift comparisons.
- Adaptive read-only printing, VPN, sign-in and slow-application runbooks,
  with each phase's reasoning retained in the report.
- Local ZIP case bundles with a file-by-file privacy preview, consistent
  pseudonyms, optional logs, recording CSV, attached comparisons/decisions,
  SHA-256 manifests and archive CRCs.

Desktop controls and CLI commands share the Rust engine. Recordings can attach
to this PC's existing report. Collection gaps are visible; finishing a runbook
does not mean the issue is repaired, and nearby changes do not prove causation.
Existing policy checks, repair confirmations and close-while-busy handling apply.

See [the investigation guide](../docs/investigations.md) for configuration,
platform coverage, collection limits and privacy review.
